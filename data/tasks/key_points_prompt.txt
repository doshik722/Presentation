Для каждой темы из списка в конце определи, какие части темы обязательно должна раскрыть хорошая
презентация из указанного числа слайдов (если не указано — из стольких, сколько нужно для раскрытия темы)
для указанной аудитории (если аудитория не указана — для самой ожидаемой по запросу). Аудитория уже знает
базовые понятия своей области: тезисы раскрывают саму тему, а не повторяют основы.
Твой ответ станет эталоном для проверки таких презентаций.

## 1. Тезисы — по числу слайдов

Тезис — короткое название одной части темы, как заголовок слайда.
Число тезисов определяется числом слайдов у темы: один тезис раскрывают на одном-двух слайдах,
титульный и заключительный слайды не считаются. Больше 10 тезисов не делай: в длинной презентации
один тезис занимает несколько слайдов. Если число слайдов не указано — столько тезисов, сколько нужно
для раскрытия темы, но не больше 10.
Например: 1 слайд — 1 тезис, 3 слайда — 2–3, 5 слайдов — 3–4, 10–12 слайдов — 6–10, 20 слайдов — 10.
Пример для темы «Фотоэффект» (её нет в списке, пример только для понимания):
- Опыты Столетова
- Законы фотоэффекта
- Почему волновая теория не объясняет фотоэффект
- Уравнение Эйнштейна для фотоэффекта
- Красная граница фотоэффекта
- Применение: фотоэлементы и солнечные батареи

Правила:
- тезис — часть темы, которую объясняют на одном или нескольких слайдах; отдельная дата, число или имя — не тезис;
- тезисы не повторяют друг друга;
- включай то, без чего тема раскрыта не полностью; базовые понятия области, которые аудитория
  уже знает, отдельными тезисами не выноси.

Для каждого тезиса укажи:
- title — сам тезис, до 8 слов;
- terms — 2–5 ключевых понятий, без которых этот тезис не раскрыт;

## 2. Контрольные факты — обычно от 3 до 8 на тему

Точные сведения, которые верная презентация должна передать без ошибок: даты, числа, формулы, имена,
названия документов. Только общепризнанное; если не уверен — не включай.
Если слайдов 1–3 — не больше 3 фактов. Если в теме нет общепризнанных точных сведений (творческий или
бытовой запрос, выдуманная компания) — оставь список фактов пустым, не придумывай их.
- claim — факт одним предложением;
- key — короткое конкретное значение: дата, число, имя, название или короткая формула вроде \eta < 2/L;
  не целое неравенство или вывод и не общее утверждение («сыграл ключевую роль»).

## 3. Источники

Используй веб-поиск. Опирайся на учебники, программы университетских курсов, энциклопедии.
Укажи источники, которые действительно использовал (название и URL), минимум один на тему.

## Формат ответа

Только один блок JSON, без текста до и после. Обработай все темы, id копируй без изменений.
Ключи латиницей, значения на русском. Формулы — в LaTeX без знаков $, например x_{k+1} = x_k - \eta \nabla f(x_k).
