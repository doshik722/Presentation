Для каждой темы из списка в конце определи, какие части темы обязательно должна раскрыть хорошая
презентация из указанного числа слайдов (если не указано — из стольких, сколько нужно для раскрытия темы)
для указанной аудитории (если аудитория не указана — для самой ожидаемой по запросу). Аудитория уже знает
базовые понятия своей области: тезисы раскрывают саму тему, а не повторяют основы.
У некоторых тем есть строка «запрос» — полный текст пользователя. Тогда тезисы раскрывают именно этот запрос
и учитывают его условия: план, данные, подробности, которые дал пользователь; тема — только его краткое название.
Твой ответ станет эталоном для проверки таких презентаций: программа будет сравнивать с тезисами слайды
презентации и искать на них ключевые слова тезисов.

## 1. Тезисы — по числу слайдов

Тезис — одна часть темы, которую объясняют на одном-двух слайдах. Титульный слайд не считается.
Если слайдов больше трёх, последний тезис — заключение презентации: главный вывод из неё.
Больше 13 тезисов, не считая заключения, не делай: в длинной презентации один тезис занимает несколько слайдов.
Если число слайдов не указано — столько тезисов, сколько нужно для раскрытия темы, но не больше 13.
Например (не считая заключения): 1 слайд — 1 тезис, 3 слайда — 2–3, 5 слайдов — 3–4, 10–12 слайдов — 6–10,
20 слайдов — 13.

Для каждого тезиса укажи:
- title — название части темы, как заголовок слайда, до 8 слов;
- statement — одно предложение, до 25 слов: что именно слайд должен донести. Утверждение, а не тема:
  не «Законы фотоэффекта», а «Число выбитых электронов растёт с яркостью, а их энергия — только с частотой»;
- key — 5–7 ключевых слов и сочетаний, которые обязательно будут в тексте слайда, раскрывающего тезис:
  годы, числа с единицами, имена, названия, термины. Каждый — 1–4 слова, в начальной форме, без кавычек;
  год — числом, без «г.» и «года» (1905, 336 до н. э.). Ключи — то, что знает и напишет хорошо подготовленный
  автор презентации для этой аудитории и что есть в учебниках и Википедии; не номера статей, форм и документов,
  если тема не о них самих. Не формулы и не общие или оценочные слова вроде «развитие», «важный», «удивительный»,
  «будущее». Даты и числа проверяй по источникам: программа ищет ключи на слайде с точностью до окончаний.

Пример для темы «Фотоэффект», 10 слайдов (её нет в списке, пример только для понимания):
- Опыты Столетова
- Законы фотоэффекта
- Почему волновая теория не объясняет фотоэффект
- Уравнение Эйнштейна для фотоэффекта
- Красная граница фотоэффекта
- Применение: фотоэлементы и солнечные батареи
- Вывод: энергию электронов задаёт частота, а не яркость
Три из них полностью:
- title: Опыты Столетова
  statement: Столетов показал, что фототок пропорционален интенсивности света и возникает практически без задержки
  key: Столетов, 1888, фототок, интенсивность света, ток насыщения, без задержки
- title: Уравнение Эйнштейна для фотоэффекта
  statement: Энергия фотона расходуется на работу выхода, а её остаток становится кинетической энергией электрона
  key: Эйнштейн, 1905, энергия фотона, работа выхода, кинетическая энергия, квант света
- title: Вывод: энергию электронов задаёт частота, а не яркость
  statement: Фотоэффект показал, что свет поглощается порциями, энергия которых зависит только от частоты
  key: кванты света, частота, яркость, энергия электронов, волновая теория

Правила:
- тезисы не повторяют друг друга, ключевые слова разных тезисов — тоже;
- включай то, без чего тема раскрыта не полностью; базовые понятия области, которые аудитория
  уже знает, отдельными тезисами не выноси;
- тезисы и key — о самой теме, а не о презентации: без слов «презентация», «план», «слайд», названий программ
  и числа слайдов;
- данные, которые пользователь дал в запросе (цифры, имена, даты), обязательно входят в key своих тезисов;
- в творческом или бытовом запросе без точных сведений key — главные слова и понятия этой части.

## Формат ответа

Только один блок JSON, без текста до и после. Обработай все темы, id копируй без изменений.
Ключи JSON латиницей, значения на русском; если запрос просит презентацию на другом языке — title, statement
и key на языке презентации (key ищется на слайде дословно). Пример показывает формат:

{
  "topics": [
    {
      "id": "t000",
      "key_points": [
        {
          "title": "Уравнение Эйнштейна для фотоэффекта",
          "statement": "Энергия фотона расходуется на работу выхода, а её остаток становится кинетической энергией электрона",
          "key": ["Эйнштейн", "1905", "энергия фотона", "работа выхода", "кинетическая энергия", "квант света"]
        }
      ]
    }
  ]
}
