Для каждой дисциплины из списка в конце найди с помощью веб-поиска одну-две рабочие программы дисциплины
(РПД) российских вузов для бакалавриата или специалитета, опубликованные на сайтах вузов, лучше 2020 года и новее.
Выпиши темы из тематического плана программы: разделы и темы лекций.

Правила:
- темы выписывай дословно, как в программе; ничего не придумывай и не переформулируй;
- если в программе тема — длинный перечень через запятую, выпиши её целиком одной строкой;
- выпиши все темы тематического плана, но не больше 15 на программу;
- для каждой программы укажи вуз, направление подготовки с кодом, курс, на котором читается дисциплина,
  и прямую ссылку на документ программы;
- если найти программу не удалось, оставь для дисциплины пустые списки — это лучше, чем выдуманная программа.

## Формат ответа

Только один блок JSON, без текста до и после. Обработай все дисциплины, id копируй без изменений.
В поле program у темы — номер программы в списке programs, с нуля. Пример показывает формат:

{
  "disciplines": [
    {
      "id": "d00",
      "programs": [
        {
          "university": "Название вуза",
          "direction": "01.03.02 Прикладная математика и информатика",
          "course": 2,
          "url": "https://..."
        }
      ],
      "topics": [
        {"title": "Тема дословно из программы", "program": 0}
      ]
    }
  ]
}
