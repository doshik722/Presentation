# Источники

- `wiki_cache/` — сохранённые ответы API Википедии (`tools/cache.py`): `searches.jsonl` — выдачи поиска,
  `pages.jsonl` — статьи по названиям (введение, номер правки, URL), `articles.jsonl` — статьи по разделам.
  Каждый ответ запрашивается один раз; повторные прогоны и сравнения моделей идут по тем же ответам.
  `articles.jsonl` начат со статей пилота (скопированы из `wiki_pilot/`).
- `wiki_pilot/` — пилотный корпус 15–16.10.2026 (8 тем): `articles.jsonl` — 1627 русских и 1418 английских статей
  по разделам, `topics.jsonl` и `topics_v2.jsonl` — запросы и живая выдача первого и второго запуска.
  Описание и выводы — EXP-006 в `docs/experiments.md`.
- `tokenizer_sample.jsonl` — 600 разделов Википедии для замера плотности токенизаторов (EXP-005).
