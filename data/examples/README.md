# Примеры презентаций в DSL

Примеры написаны вручную по спецификации [docs/dsl_spec.md](../../docs/dsl_spec.md).
Файлы содержат только DSL: комментарии внутри них считались бы ошибками разбора.

| Файл | Тип темы | Что проверяет |
|---|---|---|
| `gradient_descent.txt` | technical | 12 слайдов: абзацы и списки, формулы, графики функций, нативный график, схемы с подписями стрелок, картинки |
| `serf_reform.txt` | humanities | 12 слайдов: абзацы и списки, цитата с атрибуцией, ленты времени, круговые графики, схемы, картинки |
| `broken.txt` | — | ошибки разбора и восстановление после них |

## Ожидаемый разбор `broken.txt`

| Строка | Текст | Ожидание |
|---|---|---|
| 1 | ```` ```dsl ```` | ограждение: пропуск, не ошибка |
| 2 | `Вот ваша презентация…` | ошибка `untagged` |
| 3 | `#TITLE` до слайда | ошибка `outside_slide` |
| 4 | `#SLIDE 1` | новый слайд, номер молча игнорируется |
| 5 | `#TITLE: Что такое переобучение` | заголовок слайда 1 |
| 6 | второй `#TITLE` | ошибка `duplicate_title` |
| 7 | `#BULLET` | пункт слайда 1 |
| 8 | `#SUBTITLE` | ошибка `unknown_tag` |
| 9 | `#BULLET` без двоеточия | ошибка `missing_colon` |
| 10 | `#BULLET:` | ошибка `empty_value` |
| 11 | `#CHART` с разной длиной `x` и `y` | ошибка `bad_value` |
| 12–13 | два `#SLIDE` подряд | слайд 2 пустой → удаляется с предупреждением `empty_slide` |
| 14 | `#BULLET` | слайд 3, предупреждение `missing_title` |
| 15 | корректный `#CHART` | график слайда 3 |
| 16 | `#PLOT: y = x^` | ошибка `bad_value` (незаконченное выражение) |
| 17 | `#DIAGRAM` | схема слайда 3 |
| 18 | `#IMAGE` | третий крупный визуал: парсер сохраняет, сборщик не рисует (`overflow`) |
| 19 | `#TIMELINE` с одним пунктом | ошибка `bad_value` (нужно от 2 пунктов) |
| 20 | ```` ``` ```` | ограждение: пропуск |

Итог: содержательных строк 18, корректных 9, `parse_rate` = 9/18 = 0,5; в презентации 2 слайда.
