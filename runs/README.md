# Результаты запусков

Ниже описан план сохранения результатов; автоматическая запись пока не реализована.

Создаём отдельную папку для каждого запуска и не перезаписываем старые результаты.
Сохраняем раскрытую конфигурацию, версии и хеши кода, исходные ответы, PPTX,
технические метрики, ошибки и формы ручной оценки. Связываем папку с записью
в `docs/experiments.md` через `run_id`.

Исключаем содержимое запусков из Git. Для важных запусков отдельно сохраняем
архив в постоянное хранилище; на Kaggle сохраняем версию с output-файлами.
Не рассчитываем на восстановление незавершённой интерактивной сессии.

В будущих RL-запусках также сохраняем состояния оптимизатора, scheduler, RNG,
положение в данных, шаг обучения и критик PPO. Пока не реализовали RL-resume.

В автоматически создаваемый `metrics.jsonl` не добавляем комментарии, поскольку
формат JSONL их не поддерживает. Во все редактируемые исходники добавляем пояснение
в начале; в ноутбуках используем первую Markdown-ячейку.
