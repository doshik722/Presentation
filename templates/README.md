# Шаблоны презентаций

Используем одинаковый сборщик и оформление для всех моделей.
В первой версии запланированы текстовые слайды, заметки и ссылки.
Компоновку макетов `title` и `bullets` предстоит реализовать.
Добавим шаблоны, формулы, диаграммы и изображения после проверки текстового пути.
Не считаем успешное сохранение PPTX доказательством отсутствия переполнений.
