# Корпус Википедии и поиск BM25 (15–16 октября 2026)

Подход: заранее собрать статьи Википедии под задания и при обучении искать по ним своим BM25, повторяя выдачу
живого поиска Википедии. Отменён 16.10.2026 в пользу живого API с сохранением ответов. Ход и результаты —
EXP-006 в `docs/experiments.md`, решения — `docs/decisions.md` (записи от 15–16.10.2026).

| Файл | Что это | Где лежал |
|---|---|---|
| `corpus.py` | сборщик корпуса: поиск по теме и `terms`, ссылки из введений, английские версии | `src/presentation_rl/tools/` |
| `test_wiki_corpus.py` | тесты клиента Википедии и сборщика (версия на 16.10.2026) | `tests/test_wiki.py` |
| `wiki_corpus_pilot.ipynb` | запуск сборщика на 8 темах пилота | `notebooks/` |
| `search.py` | BM25F по разделам: поля, стеммер Snowball, подобранные веса | `src/presentation_rl/tools/` |
| `test_search.py` | тесты BM25F | `tests/` |
| `wiki_search_calibration.ipynb` | подбор весов по совпадению с живой выдачей, разбор промахов | `notebooks/` |
| `web.py` | пустая заготовка поиска из каркаса проекта | `src/presentation_rl/tools/` |

Код не запускается из этой папки: модули импортировались как `presentation_rl.tools.*`, а `search.py` требует
пакет `snowballstemmer`. Данные пилота — `data/sources/wiki_pilot/`.
