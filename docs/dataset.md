# Набор заданий

Версия от 13.10.2026. Данные — `data/tasks/tasks.json` (449 заданий). Решения — [decisions.md](decisions.md), раздел 6.

## Источники

- **Рабочие программы дисциплин российских вузов.** 36 дисциплин поровну по типам, по 2 программы на дисциплину (72 программы),
  837 тем из тематических планов (`data/tasks/raw_topics.json`, ссылки — `raw_topics.md`). После очистки — 674 темы-семейства
  (`syllabus_topics.xlsx`); отобрано автором 155 тем, в среднем по 4 на дисциплину, равномерно по курсу.
  Тема подаётся как «тема + аудитория».
- **Реальные запросы пользователей — WildChat-1M** (ODC-BY). Из 837 989 диалогов 87 127 русских; в 1194 найдены просьбы
  о презентации (поиск по слову с опечатками и разговорными формами, `notebooks/wildchat_presentations.ipynb`), 960 разных;
  504 — действительно просьбы сделать презентацию; отобрано автором 262. Запрос подаётся модели текстом пользователя:
  убраны ссылки на предыдущие реплики, вставленные документы длиннее ~1500 символов, просьбы о коде и личные данные.
- **Составленные запросы** для сценариев, редких в WildChat (быт, научпоп, рабочие отчёты с данными): 32, из них 12 — автора.

## Деление

Четыре непересекающиеся выборки: SFT — 90, train — 274, validation — 25, test — 60.
Делим по семействам: перефразировки одной темы, в том числе из разных источников, попадают в одну выборку
(430 семейств, из них 17 из двух и более заданий). Деление стратифицировано по источнику, сценарию (учёба или нет),
типу темы и наличию курса; в test 12 заданий с курсом (20%), чтобы метрики по ним можно было показать отдельно.

## Примеры для SFT

Для каждого из 90 заданий SFT составлена полная презентация в DSL: по 30 — Claude Opus 5.5, Codex Sol 6.1
и Gemini 3.1 Pro Preview, у каждой модели 6 пакетов по 3–6 запросов, новый чат на пакет, веб-поиск включён
(для сверки фактов). Задания разложены между моделями по слоям (источник, тип темы, сценарий, заданы ли слайды,
курс, аудитория, материал). Промпт уточнялся по итогам пакетов (6 версий); какой пакет по какой версии составлен
и какие презентации исправлялись — в `data/tasks/sft/sft_meta.yaml`.

Набор собирает `python -m presentation_rl.sft_data` из сырых ответов (`data/tasks/sft/<модель>/answerN.txt`,
исправления — `answerN_fix.txt`) в `data/tasks/sft/sft_dataset.jsonl`; запрос в примере — в том виде, в каком
его увидит модель («Поиск: нет», картинки — по заданию). При сборке проверяется: все задания на месте, разбор без
ошибок, все формулы рисуются, нет `#IMAGE` там, где картинки запрещены. Итог: 90 примеров, ошибок нет.

## Ограничения

- Темы, аудитории, сценарии, семейства и очистка запросов предложены автоматически и проверены автором выборочно; отбор тем и запросов — автора.
- Тексты тем из программ получены из документов через пересказ; возможны мелкие расхождения с оригиналом.
- В WildChat учебные запросы преобладают (около 70%), бытовые и научно-популярные почти отсутствуют — они добавлены составленными запросами.
- Все 90 примеров SFT — без вызовов поиска; примеры с поиском и `#SOURCE` составляются после корпуса и инструментов.
- У 14 примеров SFT нет `#PLAN`: план стал обязательным с пакета 3.
- Gemini пишет короче остальных (медиана 8,5 слайда против 12); разнообразие длины сохранено намеренно.
- Формат примеров SFT проверен автоматически; содержание проверяет автор.
